# 💸 쉽고 빠른 정산앱 (Moim-app)

골치 아픈 단체 모임 정산, 1분 만에 끝내는 가장 가벼운 모바일 웹 서비스입니다.
카카오 장소 검색과 영수증 사진 기록을 통해 스마트하고 투명한 모임/총무 관리를 돕습니다.

## ✨ 주요 기능

* **예산 및 사전 회비 관리**: 모임 생성 시 사전 회비를 설정하여, 수금된 회비 대비 남은 지출 예산을 한눈에 파악할 수 있습니다.
* **스마트 지출 타임라인**: 핀(📍) 뱃지 형태의 시각화된 타임라인으로 전체 지출 내역을 추적합니다.
* **장소 자동완성 (카카오 로컬 API)**: 직접 상호명을 외워서 치지 않아도, 스마트 검색을 통해 실제 매장명과 도로명 주소를 자동으로 불러옵니다.
* **영수증 원본 캡처 보관**: 결제 영수증이나 음식 사진을 지출 내역에 바로 첨부하여 분쟁을 없애고 투명도를 높입니다.
* **원터치 정산서 발급 및 공유**: 지출을 기반으로 인원별 최종 납부액을 자동 계산하고, **이미지 저장** 혹은 **클립보드(카카오톡) 텍스트 공유**를 지원합니다.

## 🛠️ 기술 스택
- **Frontend / Backend**: Next.js (App Router), React
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Database / ORM**: MySQL, Prisma
- **External API**: Kakao Maps Local API (장소 검색)
