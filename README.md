# 💸 쉽고 빠른 정산앱 (Moim-app)

> **한 줄 정의**: 복잡한 모임 비용 정산의 투명하고 효율적인 기록 및 관리를 통해 정산의 불편함을 해소하고, 참여자 간의 금전적 오해를 방지하여 즐거운 모임 경험을 제공하는 **모임 정산 애플리케이션**입니다.

---

## 🎯 기획 배경 및 목표

기존 모임 후 발생하는 경비 정산은 수기 기록, 복잡한 계산 등으로 인해 시간 소모와 오류 발생 가능성이 높았습니다. 이러한 불편함을 해소하기 위해, **로그인 없이 스마트폰 내 로컬 저장 공간(Recent History)과 공유 토큰(URL) 방식**을 활용하여 개인정보 유출 우려를 최소화하고 사용자 접근성을 극대화한 정산 앱을 개발하게 되었습니다.

## ✨ 핵심 가치 및 차별점

- **No 로그인, 직관적인 사용성**: 로그인 절차를 없애고 로컬 스토리지와 공유 링크로 빠르게 모임에 접근 및 관리합니다.
- **투명한 기록과 자동 계산**: 지출/수입 등록 시 전체 금전적인 흐름이 자동 계산되며, 장기/단기 모임 성격에 유연하게 대응합니다.
- **카카오 로컬 API 기반 장소 연동**: 사용처를 일일이 타이핑할 필요 없이, 스마트 검색을 통해 도로명/지번 주소까지 정확하게 기록합니다.
- **웹 영수증 사진 및 원터치 공유**: 결제 영수증 업로드(WebP 자동 압축) 기능과 최종 정산서 이미지/텍스트(클립보드 방식) 복사를 통한 간편한 카카오톡 공유를 지원합니다.

## 🧑‍🤝‍🧑 주요 타겟 및 시나리오

- **타겟 사용자**: 친구, 동호회, 가족 등 잦은 모임 특성상 빈번한 경비 계산으로 번거로움을 느끼는 총무 및 모임원.
- **핵심 시나리오**: 
  1. 앱 실행 후 '새 모임 생성' (초기 회비, 모임 주기, 계좌 정보 등 등록)
  2. 회식 등 비용 지출 시 '지출 내역 기록' (장소 검색 및 영수증 자동 WebP 최적화 첨부)
  3. 모든 내역을 반영해 '자동 최종 정산' 수행 및 개인별 송금액 산출
  4. '정산서 공유' 기능을 통해 모임원들에게 깔끔하게 공유

## 📈 성공 지표 (KPI)
- 월간 활성 사용자 수 (MAU)
- 생성된 총 모임 수 및 지출 기록 건수
- 최종 정산 완료율 및 정산서 공유 버튼 클릭 횟수
- 사용자 재방문율

## 🛠️ 기술 스택
- **Frontend / Backend**: Next.js (App Router), React
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Database / ORM**: MySQL, Prisma
- **External API**: Kakao Maps Local API (장소 검색)
- **Deployment**: Docker (Standalone Build), Nginx Reverse Proxy
